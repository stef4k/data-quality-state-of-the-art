# Data Quality State of the Art
State of the art for the topic of __data quality__, which was the project of the course Big Data Seminars of BDMA (UPC, June 2025), by Kristóf Balázs and Stefanos Kypritidis:
- [Final paper](https://github.com/stef4k/data-quality-state-of-the-art/blob/main/paper_state_of_the_art.pdf)
- [Poster presentation](https://github.com/stef4k/data-quality-state-of-the-art/blob/main/poster_state_of_the_art.pdf) (eBISS 2025)

  
**Research question:** Which automated error-detection strategies do current data quality tools use, and how well does each strategy cover the main data quality dimensions and error types found in data?
 
We compare six tools (CODED, DataVinci, Deequ, KATARA, Raha, Uni-Detect) on accessibility, accuracy, completeness, consistency and timeliness. No single tool covers all error types, and most are weak on timeliness, with Deequ as the exception.
